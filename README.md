# 🧬 Aila Nano

Um dos projetos mais experimentais (e trabalhosos) da Aila: um **Small Language Model (SLM)** próprio, construído do zero.

A versão mais avançada do Aila Nano possui aproximadamente:

### 🔢 **51 milhões de parâmetros**

| Componente | Configuração |
|---|---|
| Arquitetura | Decoder-only Transformer |
| Embedding Dimension | 512 |
| Layers | 12 |
| Attention Heads | 8 |
| KV Heads | 4 |
| Attention | Grouped Query Attention |
| FFN Dimension | 2048 |
| FFN | SwiGLU |
| Vocabulary | 8192 |
| Contexto de treinamento | 256 tokens |

Todo o treinamento foi feito **em CPU**, sem GPU disponível. Sim, é lento. Sim, dói. Sim, valeu a pena aprender.

### 🛠️ Tecnologias

* PyTorch
* AdamW
* Cosine Learning Rate
* Checkpoints
* Resume Training
* TensorBoard
* Memmapped datasets
* Fine-tuning
* Instruction tuning
* SentencePiece
* BPE

### 📚 Datasets

* TinyStories
* WikiText-103
* Dados específicos da Aila
* Instruções
* Dados em português

### 💭 Filosofia

> **Mais parâmetros não significam automaticamente uma IA melhor.**

O foco do Aila Nano é priorizar **qualidade e curadoria dos dados** antes de simplesmente empilhar mais parâmetros. Um modelo pequeno bem treinado pode superar um modelo grande mal treinado.

```text
GPU: 0
CPU: sim
Paciência: necessária
Tempo de treinamento: bastante
"Vai terminar hoje?": não sabemos
```
